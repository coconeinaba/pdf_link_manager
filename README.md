# PDF リンク配置マネージャー 3.1.1

ページサイズや回転角が異なるPDFへ、各ページの表示上の左上を原点としてリンクを追加・編集するTkinterアプリです。元PDFは変更せず、必ず別名PDFへ保存します。

## 既存リンクの読み込み

PDF内に既存リンクがある場合、「リンク情報を登録しますか？」と確認します。

- 「はい」: ページ移動、名前付き移動先、URLリンクを登録予定一覧へ読み込み、編集対象にします。
- 「いいえ」: 一覧へ読み込まず、プレビュー上の青い破線として表示します。保存時も加工・修正せず元のまま残します。
- リンクがないPDF: 確認画面を表示せず、そのまま開きます。

Acrobat Pro等が作成する直接 `/Dest` や間接アクション辞書もページリンクとして読み込みます。解決できない名前付き移動先や未対応アクションは、「はい」を選んでも青い破線のまま保持します。

## 主な機能

- ページ番号を入力して指定ページへ移動
- ページごとの左上を `(0, 0)` とするX・Y・幅・高さ指定（mm／pt）
- 新規範囲の初期値はX=`0`、Y=`0`、幅=`1 mm`、高さ=`1 mm`
- ページ外へはみ出す範囲も入力値のまま適用
- 全ページ、範囲、個別、奇数、偶数ページの指定
- PDF内ページ／名前付き移動先／Web URLへのリンク
- リンク先表示を「全体表示」「100%表示」「幅に合わせる」「描画領域の幅に合わせる」から選択
- リンクボックスの表示／非表示、枠色、枠幅、実線／破線／下線
- ハイライトを「なし」「反転」「アウトライン」「プッシュ」から選択（新規の初期値は「なし」）
- 既存リンクと追加予定リンクの重なり検査
- 登録予定のJSON保存／読み込み、複製、有効切替、削除、元に戻す／やり直す
- 検査・取込・保存の詳細はエラーログへ保存。リンク単位のページ、X、Y、幅、高さを記録
- 別名PDFへの1回保存。`reload_page()`、保存後の `saveIncr()`、一時PDFの置換に依存しません。
- 修復が必要なPDFは保存を中止し、意図しないコンテンツ変更を防ぎます。

## 重要: PyMuPDFのバージョン

PyMuPDFは安全確認済みの `1.27.2.3` に固定しています。PyMuPDF 1.28系には、コンテンツストリームの再生成時に文字・数式などの位置や表示が変化する未解決の回帰があります。

アプリは起動時とPDF保存時にバージョンを検査します。異なるバージョンが入っている場合は処理せず、正しい導入コマンドを表示します。また、保存時に `clean=True` は使用しません。

関連情報: [PyMuPDF Issue #5054](https://github.com/pymupdf/PyMuPDF/issues/5054)

同梱の3.1.0版PDFマニュアルにある「PyMuPDF 1.28.0以降」という記述は、この3.1.1版のREADMEと`requirements.txt`によって置き換えられます。

## インストール

Python 3.10以降を推奨します。Python 3.14を含め、PyMuPDFは必ず `1.27.2.3` を使用してください。

WindowsのPowerShellまたはコマンドプロンプト:

```powershell
python -m pip install --force-reinstall -r requirements.txt
python -c "import pymupdf; print(pymupdf.__version__, pymupdf.VersionFitz)"
python app.py
```

macOSのターミナル:

```zsh
python3 -m pip install --force-reinstall -r requirements.txt
python3 -c "import pymupdf; print(pymupdf.__version__, pymupdf.VersionFitz)"
python3 app.py
```

python.org版Pythonには通常Tkinterが含まれます。環境によってはTkinterを別途導入してください。macOS向けのキー割り当ては実装していますが、本配布物はWindows上で検証しています。

実行可能な `.bat`／`.command` は同梱していません。`start_pdf_link_manager_windows.txt` と `start_pdf_link_manager_mac.txt` は、手動実行するコマンドの確認用です。

## 基本操作

1. 「PDFを開く」で元PDFを選びます。既存リンクがある場合は、一覧へ登録するか選びます。
2. ページ番号欄へ番号を入力し「移動」で目的ページへ移動します。
3. プレビューの空いている場所をドラッグして赤い範囲を作ります。
4. X・Y・幅・高さ、対象ページ、リンク先、外観を調整します。
5. 「新規として追加」を押します。設定名が空欄なら自動命名されます。
6. 既存設定を直す場合は、一覧またはプレビューの黄／橙枠を選び「選択設定を更新」を押します。
7. 名前付き移動先を読み込んだ場合は、上部の「名前付き出力」を選びます。
8. 「設定を検査」の後、「PDFへ適用して保存」で別名保存します。

「名前付き出力」の初期値は「元の名前を保持」です。

対象ページの例:

- `全ページ`
- `1-5`
- `1-5,8,10-12`
- `奇数`
- `偶数`

## プレビュー操作

- 空所をドラッグ: 新しいリンク範囲
- 登録予定枠をクリック: 一覧の該当項目を選択
- 枠内をドラッグ: 位置移動
- 四隅のハンドルをドラッグ: サイズ変更
- 矢印キー: 増減量に従って位置を微調整
- Shift+矢印キー: 10倍の量で位置を移動
- Spaceを押しながらドラッグ: 表示を上下左右へ移動
- ホイール上下: 前／次ページ
- Ctrl+ホイール: マウスカーソル位置を中心に拡大／縮小
- macOSではCommand+ホイールでもカーソル位置を中心に拡大／縮小

一覧の項目を選ぶと、その設定の先頭対象ページへプレビューが移動します。現在表示中のページも対象なら、現在ページを維持します。

## 空欄時の自動命名

設定名へ入力がある場合は、その名前を使用します。空欄の場合だけ、対象範囲を次の優先順で判定します。

1. 文字: `P5 目次`（空白・改行等を除去し最大20文字）
2. 画像: `P10 画像`
3. フォーム欄: `P3 フォーム`
4. 注釈: `P3 注釈`
5. ベクター図形: `P3 図形`
6. 判定不能: `P5 01`、`P5 02` のようなページ別連番

OCRは行いません。画像内だけに文字がある場合は「画像」になります。

## プレビューの色

- 赤: 現在編集中の範囲
- 黄／橙: 一覧へ読み込まれた編集可能リンク、または追加予定リンク
- 青い破線: 読み込まなかった既存リンク、または未対応の既存リンク

既存リンクの読み込みで「いいえ」を選ぶと、すべて青い破線になります。「はい」を選ぶと、編集可能なリンクが黄／橙枠になり、未対応のリンクだけ青い破線で残ります。

## 安全性と制限

- 元PDFと同じパスには保存できません。
- 出力先を別アプリが使用中の場合は、末尾に連番を付けた別名を提案します。
- パスワード保護PDFには対応していません。
- 電子署名付きPDFは、編集により署名が無効になる可能性があります。
- PDFビューアによって枠やハイライトの見え方が異なり、一部属性が無視される場合があります。
- 「元の名前を保持」では、表示方法は名前付き移動先の定義に従います。同じ名前を使うリンクで共有されます。
- PDFを分割・結合する後工程がある場合、名前ツリーが引き継がれない可能性があるため「ページ番号へ変換」が安全です。
- どちらの出力方式でも、まず元PDFのコピーで結果を確認してください。

## エラーログ

検査エラーや大量の警告は、画面を埋めるメッセージ一覧ではなく、PDFと同じフォルダーの `PDFリンク配置マネージャー_logs` へ保存します。出力PDFに関する警告は出力先フォルダーを優先します。そこへ保存できない場合は、OSの一時フォルダーへ退避します。

各リンクの記録には、設定名、ページ、X、Y、幅、高さ（ptとmm）、xref、例外種類を可能な範囲で含めます。画面には件数とログファイルの場所だけを表示します。
